# 勞資會議提案系統

純前端的勞資會議提案管理工具（無後端、無資料庫），支援 Excel 提案總表與 Word 提案單匯出。
所有提案資料只存在使用者自己的瀏覽器，不會上傳到任何伺服器。

## 使用方式

開啟本專案的 GitHub Pages 網址即可使用，手機、平板、電腦皆可。
手機建議用 Safari／Chrome 開啟後「加入主畫面」，使用起來就像 App。

## 功能

- 會議場次管理（屆次、次別、日期、時間、地點、主席、紀錄、勞資雙方代表）
- 提案管理：案號、類別、提案方、提案人、連署人、案由、說明、辦法、決議、執行單位、辦理期限、狀態
- 說明與辦法支援多行，匯出時自動加上「一、二、三、」編號
- Excel 匯出：提案總覽、會議場次、各場次明細、統計共 4 類工作表
- Word 匯出：一案一頁的正式提案單（A4、標楷體），可勾選多筆批次匯出成一份
- 統計總覽與關鍵字搜尋
- JSON 備份匯出／匯入

## 資料保存

資料儲存在瀏覽器的 localStorage，**不會上傳**。因此：

- 換裝置或清除瀏覽器資料後，資料不會跟著走，請定期用「⋯ → 匯出備份（JSON）」備份。
- 若要多人共用同一份提案，需要另外接後端資料庫。

## 檔案結構

```
index.html      版面與畫面
styles.css      外觀（Apple 風格外觀、深色模式、手機版）
app.js          應用邏輯（狀態、清單、表單、匯出觸發）
exports.js      Excel／Word 產生邏輯（純資料轉換，可以獨立測試）
vendor/         SheetJS、docx、lucide 與 Office 圖示
```
